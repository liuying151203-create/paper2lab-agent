# 2026-06-12 最小样例 PDF 与端到端 smoke

## 背景

Phase 1 已经具备上传、解析、清洗、chunk、PaperCard 和 QA 的完整链路。为了后续每开发一个功能都能快速实际验证，本次加入最小样例 PDF 生成器和端到端 smoke 脚本。

## 完成内容

- 新增 `paper2gnnlab_agent.samples.minimal_pdf`。
- 使用最小 PDF 语法生成一个文本型 GNN 论文 PDF，不引入额外依赖。
- 新增 `scripts/create_sample_pdf.py`。
- 新增 `scripts/smoke_e2e.py`。
- 新增样例 PDF 可解析性测试。

## 样例论文内容

样例 PDF 覆盖 Phase 1 需要抽取的核心字段：

- node classification
- Cora / Citeseer
- GCN
- cross-entropy
- Adam
- accuracy / F1
- GAT / GraphSAGE / MLP baselines
- missing details：hardware details and random seeds

## 使用方式

生成样例 PDF：

```powershell
.\.venv\Scripts\python.exe scripts\create_sample_pdf.py
```

默认输出：

```text
.tmp/smoke/minimal_gnn_paper.pdf
```

运行端到端 smoke：

```powershell
.\.venv\Scripts\python.exe scripts\smoke_e2e.py
```

脚本会执行：

1. 生成最小 PDF。
2. 上传 PDF 并计算 hash。
3. 解析 PDF。
4. 清洗文本。
5. 生成 chunks。
6. 生成 PaperCard。
7. 执行单篇 QA。
8. 校验关键 artifacts 和字段。

默认 smoke 数据写入：

```text
.tmp/smoke-runs/{timestamp}/
```
